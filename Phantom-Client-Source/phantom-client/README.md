# Phantom Client (source project)

A client-side Minecraft Fabric mod with a dark PvP menu opened by **Right Shift**, custom UI styling, saved preferences, and working graphics profile actions.

## Requirements
- Java 21
- Gradle (or use the Gradle wrapper generated by your IDE)
- Minecraft 1.21.11 with a compatible Fabric Loader and Fabric API

## Build
1. Open this folder in IntelliJ IDEA or another Gradle-compatible IDE.
2. Allow Gradle to download dependencies.
3. Run the Gradle task `build`.
4. Copy `build/libs/phantom-client-1.0.0.jar` into `.minecraft/mods` alongside Fabric API.

## Features
- Right Shift opens/closes the menu.
- Tabs: Performance, Visuals, HUD, Textures, Settings.
- Low Graphics and Balanced actions adjust cloud rendering and particle settings.
- Config saves to `.minecraft/config/phantomclient.json`.
- UI textures can be replaced in `src/main/resources/assets/phantomclient/textures/gui/`.

## Important compatibility note
This source scaffold targets Minecraft 1.21.11 and Java 21. Fabric/Yarn/API versions can change; if Gradle reports a dependency-resolution or API mismatch, update the corresponding versions in `gradle.properties` and `build.gradle` to versions published for your exact Minecraft release. A compiled JAR is not included because a successful build has not been verified in this environment.
